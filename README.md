# BorderlessFB3
Mod for Five Nights at Frickbear's 3 that adds Borderless Fullscreen support.

This mod uses UMP (https://github.com/nhaar/UMP), which means that it can be applied on top of almost any FB3-4LD data.win file (including the modded ones).

HOW TO BUILD:
- Extract all files from this ZIP
- Open ``data.win`` in UndertaleModTool
- Go to "Scripts"
- Choose "Run other script..."
- Run "build.csx" from wherever you extracted the files
- Save data.win

Alternatively, a delta patch version of the mod for a clean FB3-4LD data.win can be found in the releases.
